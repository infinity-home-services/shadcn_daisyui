Dark mode & CSP

Fields, fills, borders, floating surfaces and overlays in light and dark, side by side. This page is served under a strict script policy, so every overlay here also proves it needs no inline JavaScript.

Strict Content-Security-Policy

This response carries the policy below (as a header and a matching meta tag). Inline event handlers are blocked, so the dialog, sheet, drawer and command palette further down open, close on backdrop click and close on Esc through phx-click JS commands and the package script alone.

script-src 'self' 'nonce-…'; object-src 'none'; base-uri 'self'
